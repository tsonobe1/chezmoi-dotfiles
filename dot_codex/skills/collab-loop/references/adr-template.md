# ADR Template

## Title

短く結論が分かる題名を書く。

例:

- ノード座標の永続化は viewport 単位で行う
- Undo 履歴は command stack 方式を採用する

## Status

- Proposed
- Accepted
- Superseded
- Rejected

## Context

この判断が必要になった背景を書く。

- 何が問題だったか
- どの制約があるか
- どの前提を置くか

## Decision

採用した判断を一文で明確に書く。

## Alternatives Considered

比較した案を並べる。

### Option A

- 概要:
- 利点:
- 欠点:

### Option B

- 概要:
- 利点:
- 欠点:

## Consequences

この判断で何が起きるかを書く。

- 得られる利点
- 受け入れる欠点
- 今後必要になる対応

## Follow-up

- 必要な追加実装
- 必要なドキュメント更新
- 将来見直す条件
